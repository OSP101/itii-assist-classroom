📋 PROJECT OVERVIEW (ภาพรวมโปรเจค)
================================================================================

ระบบนี้คือ เว็บแอปสำหรับจัดการรายวิชา, เช็คชื่อแบบยืนยันตัวตน, เก็บคะแนน, 
และระบบจองคิวตรวจงานในห้องแลป

================================================================================
🚀 TECH STACK
================================================================================

Frontend: Next.js
Backend: Express.js (Node.js)
Database: MySQL
ORM: Sequelize
Real-time: Socket.io
Authentication: Passport.js + JWT (Access Token + Refresh Token)
Validation: Joi

👥 USER ROLES (ประเภทผู้ใช้)
================================================================================

1. Admin
   - สร้าง/แก้ไข/ลบบัญชีผู้ใช้ (instructor, TA)
   - เพิ่มข้อมูลนักศึกษา (Master Directory)
   - นำเข้ารายชื่อนักศึกษาทีละหลายคน (CSV/Excel)
   - ดู Log ระบบ / Performance / Traffic

2. Instructor (อาจารย์)
   - สร้างรายวิชา (ชื่อ, รหัส, ปีการศึกษา, เทอม)
   - เพิ่ม TA ให้กับวิชา
   - แบ่ง Section ให้กับวิชา
   - ลงทะเบียนนักศึกษาเข้ารายวิชาตาม Section
   - สร้างงาน (กลุ่ม/เดี่ยว)
   - สร้างและจัดการคะแนน (แก้/ขออนุมัติ/อนุมัติ)
   - สร้างรอบเช็คชื่อ
   - สร้างรอบจองคิวตรวจงาน (Queue Session)
   - ออกรายงานทั้งหมด

3. TA
   - ใช้ระบบได้เกือบทั้งหมดเหมือน Instructor
   - แก้ไขคะแนนต้องรอ Instructor อนุมัติ
   - บางเมนูระดับระบบห้ามเข้า (เช่น Logs)

4. Student (นักศึกษา)
   - ไม่มีบัญชีผู้ใช้ทั่วไป
   - ล็อกอินเฉพาะตอน "เช็คชื่อ" เพื่อยืนยันตัวตน
   - ค้นหารหัสนักศึกษา เพื่อดูผลคะแนนและสถานะต่าง ๆ

================================================================================
🔧 FUNCTIONAL REQUIREMENTS (9 ระบบหลัก)
================================================================================

1. ระบบบัญชีผู้ใช้ (User Management)
   - Login ด้วย username/password
   - Login ด้วย Google OAuth
   - JWT Access Token (15 นาที) + Refresh Token (7 วัน)
   - Role-based access control

2. ระบบจัดการนักศึกษา (Student Directory)
   - Admin เพิ่มนักศึกษาครั้งเดียว (Master Directory)
   - เก็บ: รหัสนักศึกษา, ชื่อ-สกุล, อีเมล
   - ใช้ข้อมูลเดียวกันในทุกวิชา

3. ระบบรายวิชา + Section
   - สร้างรายวิชา (Course)
   - เพิ่ม Section หลายอันภายในวิชา
   - เพิ่ม TA ให้กับวิชา
   - เพิ่มนักศึกษาเข้า Section

4. ระบบเช็คชื่อ (Attendance System)
   - สร้างรอบเช็คชื่อ (Attendance Session)
   - ตั้งค่า: PIN Code, GPS (lat/lng), เวลาเปิด-ปิด, Radius
   - เฉพาะ section หรือทั้งวิชา
   - นักศึกษาต้อง Login + ส่ง PIN + GPS + SSO Identifier

5. ระบบเก็บคะแนน (Scoring System)
   - สร้าง Score Group (งานที่ 1, Quiz, Lab Assessment)
   - Score Items แบบ Tree (ข้อใหญ่/ข้อย่อย)
   - 3 ประเภทงาน: individual, permanent_group, temporary_group
   - Workflow: normal → pending_approval → approved
   - Log ประวัติการแก้ไขคะแนน

6. ระบบกลุ่มนักศึกษา (Student Groups)
   - กลุ่มถาวร (Permanent)
   - กลุ่มชั่วคราว (Temporary)

7. ระบบจองคิวตรวจงาน (Queue System)
   - สร้าง Queue Session
   - ระบุห้อง (Room + Layout)
   - เชื่อมกับ Score Group
   - นักศึกษาเลือกที่นั่ง + ประเภทการจอง (ตรวจงาน/แก้ปัญหา)
   - สถานะ: waiting, checking, done, canceled

8. ระบบผังห้อง (Room Layout)
   - สร้างผังโต๊ะ (x, y positions)
   - หมายเลขที่นั่ง
   - ใช้ร่วมกับระบบจองคิว

9. ระบบ Log + Monitoring
   - บันทึกทุกกิจกรรม
   - Admin ดูสถิติและ Error Log

🔐 AUTH API ENDPOINTS (สร้างแล้ว)
================================================================================
